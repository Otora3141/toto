# toto 予想アシスタント

マルチ予想の組み合わせを削減するツールです。予想の範囲内なら最低でも2等が当たる買い目を作ります。

## 起動

`start.bat` をダブルクリック（または `python server.py`）→ ブラウザで http://127.0.0.1:8765/ が開きます。
Python 3 の標準ライブラリだけで動きます。

## 使い方

1. **試合設定** — 開催回を選ぶと、toto 公式サイトから対象試合と（販売中なら）投票率を自動取得します。
   過去の試合結果はサーバー起動時に自動で取得・更新されます（初回のみ数分）。
2. **予想入力** — 各試合で 1 / 0 / 2 を選びます（複数選択＝マルチ）。
   参考の勝率は「過去データ（レーティング・直接対決）」と「投票率」から独自に計算した値です（投票率が未公開の回は「-」表示で、過去データのみで計算）。
3. **買い目** — 保証レベル（2等 / 3等）を選ぶと、選んだ印の組み合わせのどれが結果になっても、
   買い目のどれかが 12 試合以上当たるように枚数を最小化します（全組み合わせで検証済み）。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `server.py` | ローカルサーバー。公式サイトの取得・解析、過去データのキャッシュ（`data/history.json`） |
| `js/model.js` | 過去データからの確率モデル（Elo レーティング＋順序ロジット、直接対決、投票率のブレンド） |
| `js/covering.js` | 組み合わせの列挙と、被覆コード（グリーディ＋局所探索）による買い目削減 |
| `js/cover-worker.js` | 買い目計算をバックグラウンドで実行 |
| `js/app.js`, `index.html` | 画面 |
| `old/` | 以前の版（手入力・組み込みデータ版） |

確率はあくまでモデルによる推定値です。
